# Security policy

## Reporting a vulnerability

Please report it privately through
[GitHub's advisory form](https://github.com/omerfsen/nvidia-nvsentinel-mcp/security/advisories/new),
not in a public issue. Say what you found, how to reproduce it, and what version you ran.

## Supported versions

Only the latest release gets fixes.

## What is in scope

The server, its image and its release files. The threat model, the controls and what was left out on
purpose are in [docs/security.md](docs/security.md). This server is for lab clusters: findings in NVSentinel
itself belong [upstream](https://github.com/NVIDIA/NVSentinel).
